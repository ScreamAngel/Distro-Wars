# Distro-Wars

Kodda bir değişiklik yaparsanız `g++ main.cpp -o oyun.exe -lraylib -lglfw3 -lopengl32 -lgdi32 -lwinmm -static-libgcc -static-libstdc++` kodunu çalıştırın (Eğer MYSYS2 kullanıyorsanız C++ altyapısı olarak). Sonrasında `.\oyun.exe` komutu ile ya da klasördeki exe dosyası ile oyunu çalıştırabilirsiniz.
